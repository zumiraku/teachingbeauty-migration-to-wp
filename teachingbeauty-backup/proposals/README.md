# 名前を隠したジョブチューンの画像（見送り）

## 結論: 差し替えない（2026-09-28・クライアント判断）

本人に確認したところ、やはり放送で名前は出ていたとのことで、今のままでよい
という返事だった。**`fix-media01.local.ps1` は流していない。本番の画像は
そのまま。** 気が変わったときのために、作ったものは残しておく。

---

クライアントから「以前のページでは苗字だけで名前は隠していたと聞いたが、
そんな画像は残っているか」と質問があった。

## 調べた結果

残っていない。元サイトの丸ごとコピー（637ファイル／うち画像542、
ハッシュ付き）を全部あたったが、名前を隠した版は無かった。

- 今まで使っていたもの: `media01.png` 471x263（大宮 康治さん がそのまま読める）
- 元サイトの `index.html` / `sp/index.html` も、同じこの画像を指していた
- もう1つ `st_img/images/media01.png` 471x200（2018-09-30）があるが、
  これは別の写真（カメラが写っている舞台裏のカット）で、名前の札は無い

つまり「以前のページ」も名前は出ていた。本人の記憶違い、という結論で
クライアントとも合意した。

## 作ったもの

`make-masked-media01.mjs` が本番の画像を取ってきて、「康治」のところ
（471x263 のうち x 381〜420 / y 144〜167）を札の地の色 rgb(160,159,159) で
塗りつぶす。苗字・さん・（鍼灸歴18年）はそのまま残る。

ページが参照しているのは原寸だけだが、WordPress が作った縮小版をそのままに
すると、隠していない名前が URL 直打ちで見えてしまう。なので3つとも作る。

| ファイル | 大きさ | バイト数 |
| --- | --- | --- |
| `media01.png` | 471x263 | 57,401（元の 62,775 より小さい） |
| `media01-300x168.png` | 300x168 | 29,616 |
| `media01-150x150.png` | 150x150 | 16,171 |

差し替えは `fix-media01.local.ps1`。ファイル名を変えないので、ページ側の
書き換えは要らない。`verify-media01.mjs` が本番の画像を取り直して、
隠した範囲に明るい画素（白い文字）が残っていないかを確かめる。
