# 名前を隠したジョブチューンの画像（クライアント確認待ち）

クライアントから「以前のページでは苗字だけで名前は隠していたと聞いたが、
そんな画像は残っているか」と質問があった。

## 調べた結果

残っていない。元サイトの丸ごとコピー（637ファイル／うち画像542、
ハッシュ付き）を全部あたったが、名前を隠した版は無かった。

- 今使っているもの: `media01.png` 471x263（大宮 康治さん がそのまま読める）
- 元サイトの `index.html` / `sp/index.html` も、同じこの画像を指していた
- もう1つ `st_img/images/media01.png` 471x200（2018-09-30）があるが、
  これは別の写真（カメラが写っている舞台裏のカット）で、名前の札は無い

つまり「以前のページ」も名前は出ていた。

## そこで作ったもの

元画像の「康治」のところ（x 381〜420 / y 144〜167）だけを隠した版を2つ用意した。
どちらも「大宮　　　さん」と読める。苗字と鍼灸歴18年はそのまま残してある。

| ファイル | 隠し方 |
| --- | --- |
| `media01-namae-mosaic.png` | モザイク |
| `media01-namae-nurikaeshi.png` | 札の地の色でベタ塗り（見た目はこちらのほうがすっきり） |

どちらにするか決まったら、`wp-content/uploads/2020/01/media01.png` を
差し替える。ファイル名を変えなければページ側の書き換えは要らない。
