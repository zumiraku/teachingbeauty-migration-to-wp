# 検証レポート：編集環境（クラシックエディター＋非破壊設定）で全39ページが崩れないこと（2026-09-17）

`EDITOR-EDIT-RISK.md` の問題（編集画面から保存するとレイアウトが崩れる）に対し、
`mu-plugin__tb-editor.php`（編集環境）と `tb-register-images.php`（画像登録）、およびテーマの修正
（WordPress 既定CSSの除去）を実装し、**ステージングと同一構成のローカル環境で全39ページを自動検証**した。

## 検証方法
1. WordPress 7.1 + 本テーマ + `teachingbeauty-fullbody.wxr` の全39ページを原本どおり投入。
2. 各ページについて：フロント表示を撮影 → クラシックエディターで開き、**何も変えずに「更新」** →
   再度撮影 → ピクセル単位で比較（Playwright / Chrome、幅1100px、全ページ縦全体、外部ウィジェットは遮断）。
3. 画像登録スクリプト実行前後でも全ページを撮影・比較。
4. トップページで実際に「写真クリック → えんぴつ → 置換 → アップロード → サイズ「中」→ 置換 → 更新」を実行し、
   写真だけが差し替わり他が不変であることを確認。

## 画像登録（tb-register-images.php）
- 39ページ・308個の `<img>` のうち 307個を登録（同一ファイルは1回のみ登録＝237添付）。
- 登録後の全ページ撮影：**39 / 39 ピクセル差ゼロ**（`big_image_size_threshold` を無効化し、元ファイルそのものを本体にしている）。
- 未登録 1件：`newpage23` の `<img src="teion">`（拡張子の無いファイル）。WordPress がファイル種別を判定できず登録不可。
  表示はこれまでどおり（相対パスのまま）。差し替えが必要になったら開発側で対応。

## 置換フローの実機確認（トップページ・コカドさんの写真）
1. 従来型の編集画面が開く（`editing-classic-screen.png`）
2. 写真をクリック → えんぴつ → 画像詳細に**「置換」が表示**（`editing-image-details-replace.png`）
3. 置換 → アップロード → 右側「サイズ」を「中」→ 置換 → 更新
4. 結果：写真だけが差し替わり、見出し・行間・サイドバーは不変（`editing-replaced-result.png`）。
   ページ全体の高さは 1px 変化（並んだ2枚のうち背の高い方が行の高さを決めるため。差し替えの正しい結果）。

## テーマ側の修正（WordPress 既定CSSの除去）
検証中に、`hari.html` で**原本には無い下線**が WordPress 版にだけ描かれていることが判明した。
原因は WordPress 本体が全ページに差し込む `global-styles` 内の
`html :where([style^="border-bottom-width"]) { border-bottom-style: solid }` が、原本の壊れた style 属性
（`style="border-bottom-width:" 3px; …`）に反応していたこと。
→ テーマで `wp-block-library` / `classic-theme-styles` / `global-styles` / `wp-img-auto-sizes-contain` を読み込まないよう修正。
全39ページを修正前後で比較：**変化したのは hari の当該下線のみ（原本どおりに消える）、他38ページはピクセル差ゼロ**。
なお `wp-block-library` には `img[class*="wp-image-"] { height:auto }` があり、画像登録後に幅・高さ属性と実寸が
異なる画像（IMG_3831.png は属性 300×303・実寸 300×297）の高さを変えてしまうため、この除去は画像登録の前提でもある。

## 実装で吸収した TinyMCE / WordPress の挙動（設定では止められないもの）
| 挙動 | 影響 | 対策（mu-plugin 内 `setup`） |
|---|---|---|
| 閉じ忘れ `<p>`/`<font>` をブラウザと違う位置で閉じる | 段落が分割され余白増 | 読込前にブラウザ自身で DOM→HTML 正規化 |
| 空の `<p>/<h1-6>/<div>` に `<br>` を挿入 | 1行分の余白増 | 空ブロックに目印コメント（TinyMCE と同じ空判定） |
| `<br>` だけの `<p>` を `<p>&nbsp;</p>` に（WP側） | 2行の余白が1行に | 一時属性で正規表現から外し保存後に除去 |
| `<br class="Apple-interchange-newline">` を削除 | 改行消失 | class 名を退避・復元 |
| `<![endif]>` 等の偽コメントを文字表示 | 文字が見える | ブラウザ正規化で通常コメント化 |
