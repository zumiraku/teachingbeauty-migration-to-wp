## この検証で見つけて修正した事項（本番でも重要）

1. **投稿日が未来扱いになる問題** — 生成時のタイムスタンプをローカル時刻のままGMTに入れていたため、タイムゾーン+9のサーバーでは全ページが「予約投稿(future)」になり非公開化。→ WXRの日付を固定の過去日時（UTC）に修正済み。**本番のロリポップ（JST）でも同じ問題が起きるため、この修正は必須だった。**
2. **サイドバーの初期ウィジェット** — WordインストールSQLインストール時に既定ウィジェットがサイドバーに入り、テーマのバナー＋店舗情報が隠れる。→ 設置時に「外観 → ウィジェット」でサイドバーを空にする（またはバナー用ウィジェットを配置）。手順書に追記。
3. **グローバルナビ** — メニューは管理画面「外観 → メニュー」で6項目を作成し、位置「グローバルナビ」に割当（本検証で設定手順を確認）。

## 再現手順（ローカル）
PHP + WP-CLI + SQLite で `wp core install` → テーマ有効化 → `wp import teachingbeauty.wxr` → 画像配置 → mu-plugin配置 → パーマリンク保存。詳細は `../MIGRATION-as-is.md`。
