# Teaching Beauty WordPress テーマ（Stage 3 成果物）

桜新町 Teaching Beauty 鍼灸整骨院・整体院の専用テーマ。現行サイト（ホームページビルダー製）のデザインを忠実に再現しつつ、**レスポンシブ・アクセシビリティ（WCAG 2.1 AA）・保守性**を内蔵する。

## デザイン再現の根拠
現行CSS（`container_5H_2c_top.css` / `main_5H_2c.css` 等）から抽出した実測トークンを `style.css` の `:root` に定義：

| 要素 | 値 |
|---|---|
| コンテナ地（クリーム） | `#fdf8e1` |
| 金色の罫線 | `#ead78d` |
| 見出し（濃い臙脂） | `#480a17` / `#561f16` |
| リンク（臙脂） | `#91384b`（hover `#cd5555`） |
| 電話番号の金 | `#a9770b` |
| 見出し=明朝／本文=ゴシック | Shippori Mincho B1 ＋ Zen Kaku Gothic New（ヒラギノ系を優先） |
| レイアウト | 現行941px 2カラムを CSS Grid で再現（本文＋右サイド） |

## 現行からの改善（品質要件）
- **レスポンシブ**：固定941pxを廃し、768px以下で1カラム・ハンバーガーメニューに。別サイト `/sp/` は不要に。
- **アクセシビリティ**：スキップリンク、ランドマーク（header/nav/main/aside/footer）、`:focus-visible`、本文16px化、`prefers-reduced-motion` 尊重。
- **保守性**：ヘッダー・フッター・サイドバーを共通パーツ化（`header.php`/`footer.php`/`sidebar.php`）。ナビはWP管理画面のメニューで編集可。お知らせ・患者様の声は投稿で追加可。
- **文字コード**：全ファイル UTF-8。

## ファイル構成
```
teachingbeauty-theme/
├─ style.css        … テーマ情報＋全デザインCSS（トークン駆動・レスポンシブ）
├─ functions.php    … テーマサポート／メニュー／ウィジェット／アセット／パンくず
├─ header.php       … 共通ヘッダー（ロゴ・電話・グローバルナビ）
├─ footer.php       … 共通フッター（サブナビ・コピーライト）
├─ sidebar.php      … 共通サイドバー（バナー＋店舗情報）
├─ front-page.php   … トップ（固定ページ本文＋新着お知らせ）
├─ page.php         … 固定ページ
├─ single.php       … 投稿個別（お知らせ・患者様の声）
├─ index.php        … 一覧／アーカイブ／検索結果
├─ 404.php          … 404
├─ searchform.php   … 検索フォーム
├─ inc/nav.js       … モバイルメニュー開閉（アクセシブル）
└─ images/          … 現行の背景・マーカー・ロゴ等の素材（28点）
```

## インストール前提（Stage 2 の設定）
- 「設定 → 表示設定」でトップに固定ページ「ホーム」、投稿ページに「お知らせ」を割当。
- 「設定 → パーマリンク」を「投稿名」に。
- 「外観 → メニュー」でグローバルナビ（primary）とフッターナビ（footer）を作成し、Stage 2 のサイト構造どおりに配置。

## 次工程（Stage 4）
本テーマに、40ページの本文移行・構造化データ（JSON-LD）・画像最適化を実装する。`functions.php` の `tb_breadcrumb()` は JSON-LD 対応の受け皿を用意済み。

## 注意
- 現行のスクリーンショット（`screenshot.png` 1200×900）は Stage 4 で実データ反映後に差し替え。
- 本テーマは現時点でサーバー未設置のためローカルで作成。FTP受領後に検証環境へ配置する。
